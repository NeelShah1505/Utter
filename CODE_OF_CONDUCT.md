# Code of Conduct

Be direct and respectful. Critique the code, not the person.

Do not harass, threaten, or post someone else's private transcripts, audio, or keys. Dictation data is personal even when it is a bug report. Redact it.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1. Report conduct problems by opening a GitHub issue marked `conduct`, or a private security report if the report itself would reveal private data.
