Natural & Clean

Default

Removes stutters, false starts, and filler words ("um", "uh") while keeping your natural voice intact.

Spoken: "um so basically I think we should push the release tomorrow" Output: "I think we should push the release tomorrow."

Professional Email

Optional

Formats conversational explanations into polished, corporate-ready emails with polite greetings and sign-offs.

Spoken: "tell sam we finished the deploy and everything looks stable" Output: "Hi Sam, I wanted to let you know that we have successfully finished the deployment, and all systems remain completely stable."

Casual Chat & Slack

Optional

Direct, concise formatting without fluff or formal salutations. Optimal for messaging team members.

Spoken: "hey can you take a look at the pull request when you get a sec" Output: "Quick ping — could you check the PR when you have a sec?"

Developer & Code

Optional

Preserves CamelCase, snake_case, variable names, programming languages, and terminal CLI syntax.

Spoken: "run cargo build release in apps slash desktop and commit to main" Output: "Run `cargo build --release` in `apps/desktop` and commit to `main`."

Transcription engine

Apple on-device is instant and needs no download. Whisper is more accurate on numbers, names, and code terms, and lets your Dictionary bias recognition — it needs a one-time model download and runs fully offline.

Whisper model

Download one model, then select it. Larger models are more accurate but slower and bigger.

Tactile Sound Feedback (Earcons)

Play crisp, subtle audio chimes when voice dictation starts and stops.

Live typing while you speak

Off by default. When on, each revision is typed with backspaces. That can fight you if you type at the same time, and it can wreck undo. Leave this off unless you want the experimental behavior.

Smart Context Auto-Routing

Only applies when AI cleanup is on. Biases the cleanup prompt from the front app (code, chat, or email). It does not change Apple speech recognition.
